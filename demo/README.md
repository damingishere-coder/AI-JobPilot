# AI JobPilot Demo 数据

该目录提供完全虚构、脱敏的示例数据，用于：

- 向新用户展示岗位分析结果长什么样
- 为前端空状态、列表、统计卡片和筛选功能提供设计参考
- 为后续“无需登录招聘平台、无需 API Key”的离线 Demo 模式准备标准输入
- 帮助贡献者编写测试和复现界面问题

## 当前状态

> 当前文件尚未自动接入应用运行流程。

现阶段它们是示例与开发契约，不应在 README 中宣称已经具备一键导入能力。真正的 Demo 模式需要完成数据加载、隔离存储、重置入口和界面标识后再发布。

## 文件说明

```text
demo/

```

- `sample-resume.md`：虚构候选人简历
- `sample-jobs.json`：虚构岗位列表
- `sample-analysis.json`：与示例岗位对应的 AI 分析结果

## 数据原则

所有示例必须满足：

- 不包含真实姓名、手机号、邮箱、公司内部信息或账号数据
- 不复制招聘网站真实岗位描述
- 不包含 Cookie、Token、API Key 或浏览器数据
- 公司、岗位、薪资与地点均为虚构或泛化内容
- 不使用真实用户的简历、聊天记录和投递结果

## 后续 Demo 模式建议

建议实现以下用户路径：

1. 用户在首页点击“体验 Demo”。
2. 系统创建独立的临时 Demo 档案。
3. 自动导入示例简历、岗位与分析结果。
4. 工作台明显显示“Demo 数据，不会执行真实投递”。
5. 所有投递按钮改为模拟状态变更，不访问招聘平台。
6. 用户可以一键重置或删除 Demo 数据。
7. Demo 数据与真实 SQLite 数据、账号配置和 Chrome Bridge 完全隔离。

## 安全边界

Demo 模式不得：

- 请求用户登录招聘平台
- 读取浏览器 Cookie 或个人档案
- 调用真实投递接口
- 使用用户已保存的 API Key，除非用户主动切换到真实模式并明确确认
- 将示例操作混入真实投递记录

相关开发任务应通过 GitHub Issue 跟踪，并在实现后补充自动化测试和使用文档。
