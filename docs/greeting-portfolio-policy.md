# 作品集与100字打招呼语

最终打招呼语按 Unicode 码点计数，不超过100个字符；正文、作品推荐语、完整网址、标点、空格均计入。AI批量分析、单独话术修正及默认话术生成共用规则，根据岗位JD与真实简历经历自然引出作品集，不编造项目成果。

个人网址通过现有服务环境变量配置，避免写死在公共代码或串到其他求职档案：

- `GREETING_PORTFOLIO_URL`：完整 HTTPS 作品网址，最多60字符。
- `GREETING_PORTFOLIO_PROFILE_ID`：网址所属档案ID，必须大于0。未配置网址时只应用100字符上限。

历史AI稿、人工稿与默认话术的原始记录保持不变。最终预览补齐网址，并在超长时保留预算内完整分句；没有可保留分句时使用简短中性介绍。已符合规则的话术保持原样。新手动保存必须符合总长度及完整网址规则，不能悄悄截断用户编辑。

编辑框、复制与确认均使用最终预览。投递快照仍保持不可变；不符合新规则的旧快照会阻止重放，不能覆盖快照或重发结果不明的消息。本次变更不触发真实HR消息或重新分析历史岗位。

验证：`gradlew.bat test --no-daemon`；前端 `pnpm test`、`pnpm typecheck`、`pnpm build:prod`。发布沿用已有受管服务，备份启动配置及数据库后切换；回滚恢复原受管启动配置和应用产物，保留发布后的业务数据库。
