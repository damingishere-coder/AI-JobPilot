# BOSS与智联扩展就绪修复

Chrome中的常驻扩展后台与磁盘上的页面脚本是两个不同的更新边界。源码或服务更新不会自动重新加载扩展；旧后台注入新版脚本后，双方版本校验可能一直失败。原实现把这种情况统一显示成“页面脚本未就绪，请刷新招聘页面”，导致用户反复刷新仍不能恢复。

1. 前端在BOSS与智联开始扫描前，通过PING核对后台协议版本。不兼容时不发扫描请求，明确提示正在运行的版本和所需版本，以及扩展重新加载步骤。停止请求不受版本门槛影响。
2. 共用脚本准备逻辑区分版本不一致与脚本不响应；版本不一致提示`EXTENSION_RELOAD_REQUIRED`及双方版本，不再无意义等待重试。
3. 同一标签页和平台的并发就绪检查共用一次注入，避免反复覆盖页面脚本实例。
4. 扩展更新为1.8.1；后台标识为`2026-09-11-content-readiness`，页面采集脚本协议仍为`2026-09-10-continuous-scan`。

发布后必须在Chrome扩展管理页重新加载“投递牛马 Chrome Bridge”，再刷新已打开的BOSS、智联及本地工作台。只重启6866或刷新招聘页不能更新正在运行的旧扩展后台。不自动重启用户Chrome、不自动开始历史扫描或投递。

验证覆盖两平台旧后台/新页面不一致、重新加载后的扫描请求、并发单次注入、停止不被升级拦截、断开扩展时不启动扫描，以及前端/后台版本标识一致性。
