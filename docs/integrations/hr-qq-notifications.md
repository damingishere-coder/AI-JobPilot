# HR 与 QQ 同步

QQ 确认卡只发送文字消息。最新 HR 消息中已完整读取的真实图片文字可以放入摘要，语音、视频和附件未读取时显示查看原会话的提示；原始媒体保留在 BOSS 和工作台，不自动转发到群或私聊。

Chrome Bridge 仅从已确认类型的图片、语音、视频、附件消息提取对应文件，不遍历未知平台卡片里的图标、推荐联系人头像和链接。未知卡片继续需要人工核验，不能通过忽略内容把不完整会话标成完整。

没有完整上下文或安全草稿时，通知明确显示已读取的 HR 原话、可核验联系人和拦截原因，不显示发送空正文的命令。QQ 可以查询详情、跳过或补充本次资料，原有发送授权、审核与发送未知冻结规则继续生效。

通知派发时再次检查仅含文字段；旧队列中的媒体通知不发送，保留失败状态与原始记录用于核验。已经发送到 QQ 的历史图片不会自动撤回或删除。

本次扩展版本为 1.10.11，部署后需要重新加载现有解压扩展并刷新 BOSS 页面，让新采集规则生效；后端阻止图片外发的保护在服务更新后立即生效。

验证：后端 `NapCatGatewayTest` 覆盖实际入队正文、无原始文件段、完整性提示、联系人回退和旧媒体队列拦截；前端 `boss-hr-dom.test.ts` 使用合成 DOM 验证推荐卡头像排除及真实图片/附件仍可采集。扩展全套回归与格式验证均需通过。

回滚通过 Git revert 和既有 RunDock 服务部署，不恢复旧数据库，不重发或删除历史通知、投递和聊天记录。
