# 智联可靠入队与完整筛选验收、发布

## 变更与证据边界

原控制器在单个岗位入队失败时中止整个批次，并将已保存但无任务的岗位作为重复岗位跳过。持久任务存储吞掉数据库写入异常，无法从旧日志确认原始 SQLite 错误类型。本次通过临时文件 SQLite 复现并发写入和锁竞争，改用先取得写保留、独立事务有限重试，并保留错误类型及档案、批次、岗位标识。

提交接口现在返回每项 `jobKey/status/retryable/errorCode/message`。`QUEUED/EXISTING/SKIPPED/INSUFFICIENT` 是已确认结果；`REJECTED/FAILED` 保留待处理项。队列上限仍为 200，队列满和临时数据库锁等待后继续；永久错误保留断点。已完成、正在执行、失败及结果未知的既有 AI 任务不由扫描自动重做。UNKNOWN 继续使用原人工对账流程。

扩展 1.7.0 增加同版本注入保护与扫描所有权检查。回执写入断点后只补交未确认岗位，关键词切换时清空该关键词的回执。旧批次无额外筛选时沿用原配置签名；非空筛选参与新签名，改变条件不能复用旧结果。
