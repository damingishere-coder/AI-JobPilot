# 智联分析体验与匹配依据修复

## 行为

- 分析图表移至岗位列表下方，默认收起；展开时才挂载图表，城市/公司图显示数量最多的10项。
- 列表将15列整合为岗位公司、薪资要求、匹配依据、状态、操作5列；固定列宽、增加行距，详情按需展开。匹配摘要和风险解析已有JSON，不再显示原始JSON或重复内容。
- 待确认卡片和列表增加“不感兴趣”，使用已有已跳过状态保留记录；更新带档案与原状态条件，避免覆盖同时发生的投递，并检查实际更新结果。
- 新增匹配依据区域，展示当前档案已保存简历、技能介绍、更新时间、关键词与普通公司阈值，可返回配置页调整。不会声称历史岗位已使用当前简历版本。
- 智联后续分析读取完整简历与岗位正文，并加入同档案当前技能介绍；技能介绍参与智联任务指纹，活跃任务仍去重保护。BOSS输入规则保持不变。
- 智联提示先核对明确求职方向/排除项，再看能力，搜索关键词不能作为实际岗位要求的证据。保持既有评分权重与用户阈值，不擅自更改用户配置。

## 已核对的原因与边界

生产当前档案的保存简历更新于2026-09-03，1746字符；2026-09-10更新的是AI技能介绍与招呼语提示。旧智联分析未使用技能介绍。当前简历未触发6000字截断，因此该截断不是已观察批次的直接原因。
旧策略偏向多投，未知信息按维度60%计分，当前阈值60；官网关键词召回范围偏宽，历史高分不等同于用户意愿。历史岗位缺少可核验的简历版本，不能证明逐条使用的是哪个上传文件。

没有修改用户简历、关键词、分数线或删除岗位。没有自动重跑历史AI任务、真实投递或发送HR消息。新规则只影响后续分析，已分析岗位不自动重算。
