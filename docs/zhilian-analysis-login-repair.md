# 智联登录检查与独立分析页

## 修改与原因

智联原先使用后端 Playwright 的登录状态拦截 Chrome 扫描，同时又把扩展连接成功显示为已登录。现在配置页和扫描前检查共用 `ZHILIAN_PAGE_STATUS`，由 Chrome 页面报告登录提示、安全验证或加载状态。检查不会打开、聚焦或跳转标签页；存在多个智联页面时优先使用可用页面。扫描仍保留目标页面自己的阻塞检查。

- `/zhilian` 只保留配置、扫描控制、日志和结果入口；登录管理直接打开智联官网，不再假装退出 Chrome 登录或保存其 Cookie。
- `/zhilian/analysis` 独立加载当前档案，可在全部岗位与本次扫描间切换。扫描结果链接带 `profileId` 与 `scanRunId`，刷新保留选择；切换档案清除旧范围和待确认选择。
- 独立分析页通过平台事件、扫描状态和 AI 队列刷新。即使筛选结果为空，后台仍有 AI 任务时也继续更新；隐藏页面暂停轮询。
- 列表与统计共享筛选范围。总览新增后端 `overview`，不再把当前页的均分、缺失字段数当成全部数据。
- 列表、统计接口增加可选 `profileId`，发现档案已切换时返回 409；旧客户端省略该参数仍保持兼容。
- 逐条投递保留审核确认。写请求丢失响应时不自动重发；Chrome 结果未知时保留 UNKNOWN 回写。
- Chrome Bridge 升级至 **1.6.5**，保持原扩展 ID、权限和 Boss 值守功能。
