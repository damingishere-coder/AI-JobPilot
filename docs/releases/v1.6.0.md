# AI JobPilot 1.6.0

应用版本：1.6.0。发布标签：`v1.6.0`。配套 Chrome Bridge：1.10.16。发布日期：2026-10-19。

## 版本内容

本版基于唯一正式主线 `main`，汇总 v1.5.0 之后已合入的功能与修复，详情见 [更新日志](../../CHANGELOG.md)。

- 求职跟进：机会与事件、简历版本与分析快照、面试准备、真实反馈和辅助排序。
- HR 沟通：后台托管、原生简历动作、QQ 决策回发、视觉操作回执、自然回复及 Humanizer 润色。
- 扫描与分析：BOSS / 智联独立采集窗口、扫描与 HR 托管隔离、启动与停止状态同步、关键词与暂停断点恢复、GPT-6.1 调用及分析重试。
- 界面保留近期功能修复和草稿保护，恢复此前的前端布局；README 的截图仍为明确标注的 v1.5 演示图。

## 下载与运行

[GitHub Release](https://github.com/damingishere-coder/AI-JobPilot/releases/tag/v1.6.0) 提供以下文件：

- `AI-JobPilot-v1.6.0.jar`：包含静态前端，需要 Java 21。
- `AI-JobPilot-v1.6.0-chrome-extension.zip`：解压后在 Chrome 加载，扩展内部版本为 1.10.16。
- `AI-JobPilot-v1.6.0-frontend-static.zip`：供已有后端集成使用。
- `AI-JobPilot-v1.6.0-source.zip`：对应标签的源码。
- `SHA256SUMS.txt`：四个发行文件的 SHA256 校验值。

首次运行见 [Windows 指南](../../WINDOWS_SETUP.md) 与 [JAR 运行说明](../releases.md)。JAR 不包含 Java、招聘平台登录态、模型凭据或完整简历识别环境，也不是免环境 Windows 安装器。

## 已有部署升级

1. 核对原服务的实际工作目录、数据库与配置路径，停止原管理器中的该服务，使用 SQLite 一致性备份并检查数据库完整性；另存旧程序版本和配置备份。
2. 更新原服务目录中的程序，保留数据库、配置、简历、浏览器资料和日志。沿用现有 RunDock / Alter 服务记录与 6866 端口，避免重复实例。
3. 从 1.5.0 升级会执行 V21 至 V38 的迁移，涉及执行协议、简历和分析快照、求职跟进、扫描日志、HR 回执及分析重试。已经应用的迁移由 Flyway 校验，不重新执行。本次发布不新增额外迁移。
4. 重新加载 Chrome Bridge 并核对 1.10.16，刷新工作台和招聘平台页面。磁盘文件版本不能证明 Chrome 已加载新版本；正在执行的浏览器任务应先妥善结束。
5. 核对实际进程、构建版本、`/api/ready`、数据库迁移版本、页面版本及主要入口。扫描、模型连接、HR 托管和真实投递分别验收，不能由 HTTP 200 或离线回归替代。

## 回滚

优先恢复升级前保存的程序、静态文件及扩展，沿用原配置；数据库保留升级后新增的业务记录。Flyway 较新迁移可能使旧程序拒绝启动，应先在数据库副本验证兼容性，再决定采用兼容修复版本。不要直接覆盖生产数据库，也不要删除迁移历史或关闭校验来强行启动旧版。

需要回退主线时创建 revert PR，经过相同验证发布新的修复版本；已发布标签与发行包保持不可变，不重写 Git 历史。

## 已知限制与验证边界

发布工作流执行前端 lint / 构建、扩展校验与测试、后端测试和带页面的 JAR 打包，并生成校验值；主线 CI 另有前端测试、类型检查、HR 视觉协议和 Windows / Linux 离线浏览器回归。

这些检查不证明任一真实招聘账号已登录、扩展已重载、模型调用可用或消息已送达。`UNKNOWN` / `SEND_UNKNOWN` 继续保留人工核对边界，发布不触发额外投递或消息发送。已有 CodeQL 中等级告警继续保留追踪，不宣称全项目没有安全问题。
