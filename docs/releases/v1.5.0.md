# AI JobPilot 1.5.0

应用版本：1.5.0。发布标签：`v1.5.0`。配套 Chrome Bridge：1.8.0。

## 正式代码来源

`main` 是唯一正式主线。1.5.0 整合此前已发布的智联/BOSS修复，以及 PR #57 的智联分析体验和 PR #58 的双平台持续采集。后续任务从最新 `origin/main` 建立独立分支，PR 以 `main` 为目标；任务完成后经过 CI、合并、现有服务部署和运行验收再清理分支。

分支数量不是版本数量。GitHub Release 和不可变标签用于识别发行版本，工作目录与部署目录不能代替版本标识。

## 运行与升级

- JAR 内含静态前端，使用 Java 21 运行；沿用现有本机配置、数据目录和服务管理器。
- Chrome Bridge 1.8.0 解压后需要手动重新加载已有扩展，并刷新招聘官网和工作台。扩展的数字版本独立于应用版本，不能降至 1.5.0。
- 本次迁移 V20 只新增 `fresh_scan_receipt` 表；升级前备份 SQLite 并执行完整性检查。
- 现有本地网页继续使用 6866，不创建第二个服务或额外公开站点。

## 验收与回滚

发布前检查整合提交的 CI、CodeQL、Release 构建和 SHA256。部署后核对进程、实际构建版本、`/api/ready`、静态资源哈希、分析页面与新接口。

回滚应恢复升级前的程序、静态资源和扩展，并沿用原用户配置。V20 新增表可保留；不得用旧数据库覆盖升级后新增的业务记录。需要回退 Git 主线时新建 revert PR，不重写已发布历史。

## 已知限制

该发行包不是独立 Windows 安装器。真实双平台完整扫描和单条/小批量投递仍需账号场景验收；自动化测试与只读页面检查不等同于实际对外投递成功。人工确认和不确定发送状态的保护继续生效。
