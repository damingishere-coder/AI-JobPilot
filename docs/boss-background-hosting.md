# BOSS 一键后台托管

在「环境配置」保存沟通资料与 QQ 设置，核对当前人物档案及 Chrome 的 BOSS 求职者账号后，点击「一键开启后台托管」。首次开启默认处理普通对话和最近 15 天待回复会话，历史范围可选择 7、15、30 天；已开启的策略保留其原有范围。你已经回复且没有新提问的会话跳过，包含已发送“谢谢”等收尾回复。面试安排、薪资承诺、资料矛盾、读取不完整等事项交给本人处理。电话和简历使用各自的分享授权。

环境页和 BOSS 浮窗的回复记录默认折叠。浮窗每 5 秒核对扩展宿主与后端的同一会话绑定，显示保存的实际历史范围和上次刷新时间，暂停/恢复使用与工作台相同的后台托管控制；首次授权与账号重新确认仍在工作台完成。读取失败时不继续显示旧的“运行中”。开启按钮不可用时，环境页列出尚未完成的确认或保存步骤。

## 运行要求与状态

- Chrome Bridge 1.10.3、Chrome 132 或以上，以及本地 Backend 服务。
- 托管使用专用 BOSS 聊天标签。自动创建标签时不激活标签、不聚焦窗口，也不使用桌面鼠标键盘；可以继续在其他标签或应用工作。
- Chrome、电脑和 Backend 必须保持运行。后台标签被冻结、卸载、退出登录或遇到验证时会暂停；必须先恢复该标签或完成登录，再点击恢复。
- 扩展 `RUNNING` 和后端 `CHROME_BACKGROUND` 的真实页面心跳均正常时，工作台才显示托管中。扩展 Service Worker 定时器本身不代表网页在线。
- 后端或扩展工作进程重启后读取已保存的意图与进度，并重新校验页面。Chrome 整体重启后，若网页只提供账号显示名而没有稳定账号 ID，需要本人重新确认账号；同名不能证明同一账号。
- 「暂停」保留授权和进度，「停止」撤销托管授权。专用聊天页检测到人工输入、点击或滚动会暂停，避免覆盖人工操作。仅「查看托管聊天页」会主动显示聊天窗口。

## 防重复发送

采集快照加密持久保存，后台分析独立于扩展的短请求。相同账号、平台会话 UID 和完整 HR 消息轮用于去重；当前页面绑定和完整来源轮在提交前再次核验。

每个发送命令只提交一次。提交前保存检查点，之后使用新增本人消息的完整正文和上下文核验结果。超时、页面变化或回执不明进入待人工核验，不自动重发。旧视觉会话需要完整身份和来源轮的只读关联，不能按联系人名字直接创建新的发送记录绕过去重。

## 验证

```powershell
node --test chrome-extension/tests/*.test.cjs
node scripts/validate-chrome-extension.mjs
.\gradlew.bat test browserRegressionTest bootJar --no-daemon
cd front
pnpm test
pnpm typecheck
pnpm lint
pnpm build:prod
```

扩展测试检查 inactive 标签、暂停竞态、持久恢复及未知结果不重发；隔离 Chromium 测试运行生产 DOM 脚本并验证正文、单次提交、回执和旧页面代次拒绝。无头浏览器不能代替真实 Chrome 隐藏标签的验收：最终须在正常 Chrome 中确认托管状态、真实聊天读取和新增本人消息，并同时检查当前活动页未变化。

## 更新与回滚

沿用现有 RunDock 的 Backend，保留数据库、配置和 HR 加密密钥，更新服务目录后重启同一服务。Chrome 中加载的扩展也须更新到同一版本并刷新工作台。

代码回滚使用任务 PR 的反向提交，Backend 和扩展一同回滚。V36 只添加加密采集队列、会话别名和发送检查点；正常回滚保留新增表及数据，不删除历史。仅在必要且获得数据恢复授权时使用部署前 SQLite 在线备份恢复数据库。

参考源码、固定提交和许可证见 [第三方代码说明](third-party-background-chat.md)。
