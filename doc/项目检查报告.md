# 项目检查报告

检查时间：2026-05-20

## 项目判断

这是一个本地运行的求职自动化 GUI 项目，整体由三部分组成：

- 后端：Spring Boot 负责 API、配置、数据库、任务调度和进度推送。
- 前端：Next.js 提供图形化配置、运行控制和岗位分析页面。
- Worker：Java + Playwright 负责实际打开招聘网站并执行自动化操作。

当前项目根目录不是 Git 仓库，无法通过 `git status` 查看版本状态。

## 技术栈确认

| 模块 | 技术 |
| --- | --- |
| 后端 | JDK 21、Spring Boot 3.5.7、Gradle、MyBatis-Plus |
| 前端 | Next.js 16、React 19、TypeScript、Tailwind CSS |
| 自动化 | Microsoft Playwright for Java 1.51.0 |
| 数据库 | SQLite |
| 运行端口 | 后端 `8888`，前端 `6866` |

## 主要目录

| 路径 | 说明 |
| --- | --- |
| `src/main/java/com/getjobs/application` | Spring Boot 应用层，包含 controller、service、mapper、entity 和配置 |
| `src/main/java/com/getjobs/worker` | 招聘平台自动化逻辑 |
| `src/main/resources/application.yaml` | 后端配置 |
| `front/app` | Next.js 页面 |
| `front/server.config.js` | 前端端口和 API 地址配置 |
| `db/getjobs.db` | 本地 SQLite 数据库 |
| `doc` | 文档目录 |

## 支持平台

当前代码中包含以下平台：

- Boss 直聘
- 猎聘
- 前程无忧 51job
- 智联招聘

README 原文曾提到拉勾，但当前代码目录和 controller 中未看到拉勾模块，因此新文档按当前代码实际情况整理为四个平台。

## 启动方式

后端：

```bash
./gradlew bootRun
```

前端：

```bash
cd front
pnpm install
pnpm dev
```

访问地址：

```text
http://localhost:6866
```

后端健康检查：

```text
http://localhost:8888/api/health
```

## 注意点

- `db/getjobs.db` 存在于当前文件夹，但 `.gitignore` 已忽略 `db/` 和 `*.db`。分享项目时建议删除或替换本地数据库。
- `Dsign.md` 是早期概要设计草案，其中部分包名、接口路径和未来规划与当前代码不完全一致。
- `Detail.md` 中有 Maven、JDK17 图片等旧内容，而当前后端实际使用 Gradle 和 JDK 21。
- 招聘平台页面结构变化会影响 Playwright 定位器，后续维护时优先检查 `worker/<platform>/Locators.java` 和平台执行类。
- 项目适合本机运行，不建议服务器部署。

## 后续建议

- 如果要继续维护代码，建议先把当前目录初始化为 Git 仓库或重新从源仓库克隆，方便追踪变更。
- 如需发布给普通使用者，可以保留新的 README 和使用指南，隐藏或移走文章类文档，降低阅读噪音。
- 如要增加平台或修复平台投递问题，应同步更新 `API接口.md`、`架构说明.md` 和 `使用指南.md`。
